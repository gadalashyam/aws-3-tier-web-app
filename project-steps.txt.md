# AWS 3-Tier Web Application Project

## Project Overview
This project demonstrates deployment of a 3-tier web application architecture on AWS.

## Services Used
- VPC
- EC2
- ALB
- RDS
- NAT Gateway
- Internet Gateway
- Bastion Host

## Architecture Diagram

![Architecture](architecture-diagram.jpeg)

## Web Tier
- Application Load Balancer
- Public Subnets

## Application Tier
- EC2 Instances
- Apache + PHP

## Database Tier
- RDS MySQL
- Multi-AZ

## Features
- Highly Available Architecture
- Secure Private Subnets
- Load Balancing
- Database Integration

   AWS Services: VPC | EC2 | ALB | RDS | NAT Gateway | Bastion Host
================================================================

----------------------------------------------------------------
 ARCHITECTURE OVERVIEW
----------------------------------------------------------------

 WEB TIER (Public Subnet)
 => Responsible for presenting information to the user via a web interface.
 => Consists of a web server that receives requests from the user's browser.
 => Handles user interactions and displays data to the user.
 => Components: Application Load Balancer (ALB)

 APPLICATION TIER (Private Subnet)
 => Responsible for processing user requests and generating responses.
 => Consists of application servers running business logic (LAMP Stack).
 => Implements business logic and application workflows.
 => Components: EC2 Instances (app-server-1, app-server-2)

 DATA TIER (Private Subnet)
 => Responsible for storing and retrieving data.
 => Consists of database servers storing structured data.
 => Ensures data consistency and efficient access to data.
 => Components: Amazon RDS MySQL (Multi-AZ)

 STEP 12: CONNECT TO BASTION HOST
================================================================

 Use MobaXterm / PuTTY / Git Bash / CMD:

 1. Connect to Bastion Host using its Public IP and keypair

 2. Save the keypair on Bastion Host:
    $ vi bastion-host.pem
    (Paste the key content → Save and Exit)

 3. Set read permissions on the key file:
    $ chmod 400 "bastion-host.pem"

 4. SSH into App Server from Bastion Host:
    $ ssh -i "bastion-host.pem" ec2-user@<PRIVATE-IP-OF-APP-SERVER-1>

================================================================
 STEP 13: INSTALL LAMP STACK ON APP-SERVER-1
================================================================

 1. Update the server:
    $ sudo yum update -y

 2. Install PHP and MariaDB dependencies:
    $ sudo amazon-linux-extras install -y lamp-mariadb10.2-php7.2 php7.2

    OR individually:
    $ sudo amazon-linux-extras install mariadb10.5
    $ sudo amazon-linux-extras install php8.2

 3. Install Apache Web Server:
    $ sudo yum install -y httpd
    $ sudo systemctl start httpd
    $ sudo systemctl enable httpd
    $ sudo systemctl is-enabled httpd

    Verify Apache is running:
    $ curl http://localhost

 4. Add ec2-user to Apache group:
    $ sudo usermod -a -G apache ec2-user

    NOTE: Logout and log back in to apply group membership.
    Verify: $ groups

 5. Set directory permissions:
    $ sudo chown -R ec2-user:apache /var/www
    $ sudo chmod 2775 /var/www && find /var/www -type d -exec sudo chmod 2775 {} \;
    $ find /var/www -type f -exec sudo chmod 0664 {} \;

 6. Install phpMyAdmin dependencies:
    $ sudo yum install php-mbstring php-xml -y
    $ sudo systemctl restart httpd
    $ sudo systemctl restart php-fpm

 7. Download and set up phpMyAdmin:
    $ cd /var/www/html
    $ wget https://www.phpmyadmin.net/downloads/phpMyAdmin-latest-all-languages.tar.gz
    $ mkdir phpMyAdmin && tar -xvzf phpMyAdmin-latest-all-languages.tar.gz -C phpMyAdmin --strip-components 1
    $ rm phpMyAdmin-latest-all-languages.tar.gz
